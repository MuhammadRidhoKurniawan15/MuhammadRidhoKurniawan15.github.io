🔬 Automatic Spice Drying Machine
Undergraduate Final Project · 2026

Rancang Bangun Mesin Pengering Rempah dengan Pengaturan Suhu Otomatis Menggunakan Artificial Neural Network (ANN). The system was developed to regulate drying temperature automatically by integrating temperature and humidity sensing, embedded control, AC voltage control, and an Artificial Neural Network controller.

The system integrates an STM32F446 Nucleo as the main controller, SHT31-F for environmental measurement, PZEM-004T for electrical monitoring, Nextion HMI for user interaction, and a TRIAC-based AC voltage controller for heater power regulation.

Technologies: STM32F446 · Artificial Neural Network · MATLAB · Simulink · PSIM · SHT31-F · PZEM-004T · Nextion HMI · TRIAC · Embedded Systems
